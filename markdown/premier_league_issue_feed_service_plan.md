# 프리미어리그 이슈 피드 서비스 기획서

## 1. 기획 배경

프리미어리그는 한국에서 가장 팬덤이 큰 해외 스포츠 분야 중 하나다. 특히 이적시장, 감독 교체, 선수 부상, 한국 선수 이슈, 빅6 클럽 논쟁은 커뮤니티와 SNS에서 빠르게 확산된다.

하지만 현재 한국 팬들이 프리미어리그 이슈를 소비하는 방식은 대부분 다음 중 하나다.

```text
1. 네이버 스포츠 기사
2. 유튜브 해설/이슈 영상
3. 인스타그램 카드뉴스
4. 축구 커뮤니티 게시글
5. X 또는 해외 기사 직접 확인
```

이 방식들은 각각 장점이 있지만, 20·30대 사용자가 짧은 시간 안에 이슈를 보고, 다른 팬들의 반응까지 함께 확인하기에는 불편하다.

이 서비스는 해외발 프리미어리그 이슈를 단순히 빠르게 전달하는 것을 넘어서, 사용자가 이슈를 숏폼처럼 넘겨보고, 댓글·투표·토론을 통해 팬들의 반응을 재미있게 확인하는 경험을 제공한다.

---

## 2. 핵심 문제 정의

현재 프리미어리그 팬들이 겪는 문제는 다음과 같다.

```text
1. 해외발 이적설과 루머가 너무 흩어져 있다.
2. 기자별 신뢰도와 루머 단계가 한눈에 보이지 않는다.
3. 기사나 커뮤니티 글은 소비하는 데 시간이 오래 걸린다.
4. 인스타그램 카드뉴스는 짧지만, 깊은 댓글·토론 경험이 약하다.
5. 커뮤니티는 반응은 많지만 정보 정리가 부족하다.
6. 특정 클럽이나 선수 이슈만 골라 보기 어렵다.
7. 큰 이슈가 터졌을 때 팬들의 찬반 흐름을 한눈에 보기 어렵다.
```

즉, 팬들은 빠른 정보뿐 아니라 다음과 같은 경험을 원한다.

```text
- 이 이슈가 정확히 무슨 상황인지 빠르게 알고 싶다.
- 이 루머가 어느 정도 단계인지 알고 싶다.
- 다른 팬들은 어떻게 생각하는지 보고 싶다.
- 내 의견도 간단히 남기고 싶다.
- 큰 이슈는 실시간으로 같이 떠들고 싶다.
```

## 3. 서비스 한 줄 정의

> 프리미어리그 이슈를 릴스처럼 넘겨보고, 댓글·투표·오늘의 토론방으로 팬들의 반응까지 즐기는 숏폼 스포츠 이슈 서비스

---

## 4. 서비스 핵심 방향

이 서비스는 단순한 프리미어리그 뉴스 요약 서비스가 아니다.

```text
기존 뉴스/카드뉴스:
이슈를 알려준다.

우리 서비스:
이슈를 보여주고, 사용자가 반응하고, 팬들의 의견 흐름까지 보게 한다.
```

핵심 방향은 다음과 같다.

```text
1. 릴스처럼 빠르게 넘겨보는 이슈 피드
2. 게시물 유형에 따라 달라지는 우측 슬라이드 경험
3. 일반 게시물은 댓글 중심
4. 논쟁형 게시물은 찬성/반대 투표 중심
5. 오늘의 토론 게시물은 실시간 토론방으로 연결
6. AI 분석은 오늘의 토론방에만 집중 적용
7. 프리미어리그 팬덤의 논쟁성과 클럽 충성도를 서비스 경험으로 활용
```

---

## 5. 기획 멘토 피드백 반영 방향

기획 멘토의 핵심 피드백은 다음과 같다.

```text
- 좋은 아이디어를 너무 빨리 버리지 말 것
- 정보 전달보다 사용자의 경험을 설계할 것
- 숏폼 UI를 따라 하는 것이 아니라, 그 안에서 어떤 식으로 소비하게 할지 설계할 것
- 댓글, 찬반, 베스트 의견, AI 분석 같은 요소로 이슈를 재미있게 만들 것
- 모든 것을 머리로만 판단하지 말고 실제 예시와 목업을 많이 만들어볼 것
```

이를 반영해 기존 기획을 다음처럼 수정한다.

```text
기존 방향:
해외발 프리미어리그 루머를 빠르게 한국어로 정리하는 서비스

수정 방향:
프리미어리그 이슈를 숏폼 피드로 소비하고,
게시물 유형에 따라 댓글·투표·토론방으로 자연스럽게 참여하는 서비스
```

중요한 점은 모든 게시물에 무거운 토론방을 붙이지 않는 것이다.

대신 게시물의 성격에 따라 참여 깊이를 다르게 설계한다.

```text
일반 게시물:
댓글만 제공

논쟁형 게시물:
찬성/반대 투표 + 결과 + 댓글 제공

오늘의 토론 게시물:
강조 효과 + 실시간 토론방 미리보기 + 토론방 진입 버튼 제공
```

## 6. 타겟 사용자

## 6-1. 핵심 타겟

```text
20·30대 프리미어리그 팬
```

특징:

```text
- 프리미어리그 주요 클럽과 선수에 관심이 있다.
- 이적설, 감독 이슈, 라인업, 부상 소식을 자주 본다.
- 긴 기사보다 짧고 빠른 요약을 선호한다.
- 커뮤니티 댓글과 팬 반응을 보는 것을 좋아한다.
- 인스타그램, 유튜브 쇼츠, 릴스 형식에 익숙하다.
```

---

## 6-2. 초기 집중 타겟

MVP에서는 전체 프리미어리그 팬을 모두 잡기보다, 반응이 강한 팬덤부터 공략한다.

```text
1. 토트넘 팬
2. 맨유 팬
3. 아스날 팬
4. 리버풀 팬
5. 첼시 팬
6. 맨시티 팬
```

초기에는 특히 한국 팬 반응이 큰 다음 이슈를 우선한다.

```text
- 손흥민 관련 이슈
- 토트넘 이적설
- 맨유 리빌딩 이슈
- 아스날 우승 경쟁 이슈
- 첼시 영입/방출 이슈
- 리버풀 감독/전술 변화 이슈
- 맨시티 규정/징계/전력 이슈
```

## 7. 핵심 사용자 경험

사용자는 앱 또는 웹에 들어오면 릴스처럼 세로형 피드를 본다.

```text
1. 사용자가 피드에 진입한다.
2. 프리미어리그 이슈 카드가 전체 화면에 표시된다.
3. 위아래로 스와이프하며 다음 이슈를 본다.
4. 관심 있는 이슈에서 오른쪽으로 슬라이드한다.
5. 게시물 유형에 따라 다른 참여 화면이 열린다.
6. 일반 게시물은 댓글을 본다.
7. 논쟁형 게시물은 찬성/반대 투표를 한다.
8. 오늘의 토론 게시물은 실시간 토론방 미리보기와 입장 버튼을 본다.
9. 사용자는 댓글을 남기거나 토론방으로 이동한다.
10. 다시 피드로 돌아와 다음 이슈를 본다.
```

이 서비스의 핵심은 단순히 뉴스를 읽는 것이 아니라, 이슈를 보고 바로 반응하는 것이다.

## 8. 화면 구조

## 8-1. 메인 피드

메인 피드는 세로형 숏폼 구조다.

```text
화면 전체:
현재 이슈 카드

상하 스와이프:
다음/이전 이슈 이동

우측 슬라이드:
게시물 상세 반응 영역 열기
```

피드 카드에 표시되는 정보:

```text
- 이슈 제목
- 핵심 요약
- 관련 클럽/선수 태그
- 루머 상태값
- 출처
- 게시물 유형 아이콘
- 댓글 수
- 투표 수 또는 토론 참여 수
```

예시:

```text
[논쟁형]
맨유는 이번 여름 브루노를 매각해야 할까?

상태: Rumour
출처: The Athletic / 현지 기자
태그: #맨유 #브루노 #이적시장

→ 오른쪽으로 밀어 의견 보기
```

---

## 8-2. 우측 슬라이드 인터랙션

우측 슬라이드는 게시물의 반응 영역이다.

사용자는 피드에서 관심 있는 게시물을 오른쪽으로 밀어 상세 참여 화면을 연다.

게시물 유형에 따라 우측 슬라이드 화면은 달라진다.

```text
일반 게시물:
댓글창

논쟁형 게시물:
찬성/반대 투표 + 결과 + 댓글

오늘의 토론 게시물:
강조된 토론 미리보기 + 실시간 토론방 입장 버튼
```

이 구조의 장점:

```text
- 피드의 빠른 소비 흐름을 유지할 수 있다.
- 모든 게시물에 무거운 토론방을 만들 필요가 없다.
- 사용자는 관심 있는 이슈에만 깊게 들어간다.
- 게시물 성격에 맞는 참여 경험을 제공할 수 있다.
```

## 9. 게시물 유형

서비스의 게시물은 크게 3가지로 구분한다.

```text
1. 일반 게시물
2. 논쟁형 게시물
3. 오늘의 토론 게시물
```

---

# 9-1. 일반 게시물

일반 게시물은 단순 소식, 짧은 루머, 부상 소식, 일정성 정보 등을 다룬다.

## 목적

```text
빠른 정보 전달과 가벼운 댓글 반응
```

## 예시 주제

```text
- 특정 선수 훈련 복귀
- 구단이 선수에게 관심을 보임
- 감독 인터뷰 요약
- 부상 업데이트
- 경기 전 라인업 예상
- 기자가 전한 짧은 루머
```

## 피드 카드 구성

```text
1. 제목
2. 2~3줄 요약
3. 출처
4. 상태값
5. 관련 태그
```

## 우측 슬라이드 구성

```text
- 댓글 목록
- 댓글 입력창
- 인기 댓글
- 좋아요/저장/공유
```

## AI 분석

```text
적용하지 않음
```

## 예시

```text
제목:
토트넘, 새 센터백 후보 리스트업

요약:
현지 보도에 따르면 토트넘은 여름 이적시장을 앞두고 센터백 보강 후보를 검토 중이다. 아직 공식 제안 단계는 아니다.

상태:
Monitoring

우측 슬라이드:
댓글창만 표시
```

---

# 9-2. 논쟁형 게시물

논쟁형 게시물은 팬들의 의견이 나뉠 만한 이슈를 다룬다.

## 목적

```text
찬성/반대 투표를 통해 가벼운 참여를 유도한다.
```

## 예시 주제

```text
- 특정 선수 영입 찬반
- 주전 선수 매각 찬반
- 감독 경질 찬반
- 유망주 기용 찬반
- 빅클럽의 고액 영입 찬반
- 클럽의 리빌딩 방향성 찬반
```

## 피드 카드 구성

```text
1. 논쟁형 질문 제목
2. 상황 요약
3. 찬성 측 핵심 근거 1개
4. 반대 측 핵심 근거 1개
5. 출처 및 상태값
6. 투표 유도 문구
```

## 우측 슬라이드 구성

투표 전:

```text
- 찬성 버튼
- 반대 버튼
- 간단한 상황 요약
- 댓글 미리보기 일부
```

투표 후:

```text
- 찬성/반대 결과 비율
- 총 투표 수
- 찬성 측 인기 댓글
- 반대 측 인기 댓글
- 댓글 입력창
```

## AI 분석

```text
적용하지 않음
```

논쟁형 게시물에는 AI 분석을 붙이지 않는다. MVP에서는 비용과 복잡도를 줄이기 위해 투표 결과와 인기 댓글까지만 제공한다.

## 예시

```text
제목:
맨유는 이번 여름 브루노를 매각해야 할까?

상황:
리빌딩과 재정 균형을 위해 핵심 선수 매각 가능성이 현지에서 거론되고 있다.

찬성 근거:
높은 이적료를 받을 수 있는 마지막 시점일 수 있다.

반대 근거:
현재 맨유에서 창의성을 대체하기 어렵다.

우측 슬라이드:
[찬성] [반대]

투표 후:
찬성 38% / 반대 62%
찬성 인기 댓글: “지금 팔아야 리빌딩 자금이 생긴다.”
반대 인기 댓글: “브루노까지 없으면 공격 전개가 안 된다.”
```

# 9-3. 오늘의 토론 게시물

오늘의 토론 게시물은 하루에 하나만 선정되는 핵심 이슈다.

## 목적

```text
서비스의 대표 참여 경험을 만든다.
```

## 선정 기준

```text
1. 팬덤 반응이 강한 이슈
2. 찬반이 명확히 나뉘는 이슈
3. 댓글이 많이 달릴 가능성이 높은 이슈
4. 특정 클럽 팬덤이 강하게 반응할 이슈
5. 하루 동안 계속 이야기할 가치가 있는 이슈
```

## 예시 주제

```text
- 손흥민은 토트넘을 떠나야 할까?
- 맨유는 감독을 교체해야 할까?
- 아스날은 우승을 위해 공격수를 반드시 영입해야 할까?
- 첼시는 고액 유망주 정책을 계속해야 할까?
- 리버풀은 살라 이후를 준비해야 할까?
```

## 피드 카드 구성

오늘의 토론 게시물은 일반 게시물보다 시각적으로 강조한다.

```text
- Today Debate 라벨
- 강조 애니메이션 또는 테두리 효과
- 실시간 참여자 수
- 현재 찬성/반대 비율
- 토론방 미리보기 댓글
- 토론방 입장 CTA
```

## 우측 슬라이드 구성

```text
- 오늘의 토론 제목
- 현재 참여자 수
- 찬성/반대 선택 버튼
- 실시간 댓글 일부
- AI 요약 미리보기
- 토론방 입장 버튼
```

## 토론방 입장 버튼

```text
[실시간 토론방 들어가기]
```

버튼을 누르면 해당 이슈의 전용 토론방으로 이동한다.

---

## 10. 오늘의 토론방 상세 기획

오늘의 토론방은 하루 1개만 운영한다.

모든 게시물에 토론방을 만들지 않고, 가장 뜨거운 이슈 하나에 사용자 반응을 집중시킨다.

## 10-1. 토론방 구조

```text
상단:
토론 주제 / 남은 시간 / 참여자 수

중앙:
실시간 채팅형 의견 리스트

하단:
찬성/반대 선택 후 의견 입력

사이드 또는 상단 카드:
AI 실시간 분석 요약
```

---

## 10-2. 참여 방식

사용자는 토론방 입장 후 먼저 입장을 선택한다.

```text
[찬성] [반대]
```

입장을 선택해야 의견을 남길 수 있다.

의견은 다음처럼 표시된다.

```text
찬성 측 댓글:
파란 진영 또는 찬성 라벨

반대 측 댓글:
빨간 진영 또는 반대 라벨
```

실제 색상은 브랜드 디자인에 맞춰 조정한다.

---

## 10-3. AI 분석

AI 분석은 오늘의 토론방에만 적용한다.

적용 이유:

```text
1. 모든 게시물에 AI 분석을 붙이면 비용이 커진다.
2. 일반 게시물에는 AI 분석까지 볼 필요가 없다.
3. 오늘의 토론방에만 집중해야 기능의 임팩트가 커진다.
4. 토론방의 핵심 차별점으로 AI를 사용할 수 있다.
```

AI 분석 내용:

```text
- 찬성 측 주요 논리 요약
- 반대 측 주요 논리 요약
- 현재 우세한 의견
- 많이 언급된 키워드
- 새롭게 떠오르는 논점
- 과열된 표현 감지
```

AI 분석 업데이트 주기:

```text
MVP:
10~15분마다 갱신

트래픽 증가 후:
5분 단위 갱신 검토
```

AI 분석 예시:

```text
AI 분석

현재 반대 의견이 61%로 우세합니다.

찬성 측은 “높은 이적료를 받을 수 있는 마지막 기회”라는 의견을 많이 내고 있습니다.
반대 측은 “대체자가 없는 상황에서 매각은 위험하다”는 논리를 중심으로 반박하고 있습니다.

최근 10분 동안은 “리빌딩 자금”과 “대체 불가” 키워드가 가장 많이 언급되고 있습니다.
```

## 10-4. 베스트 의견

토론방에는 베스트 의견 영역을 둔다.

선정 기준:

```text
- 좋아요 수
- 답글 수
- 신고 수가 낮은 댓글
- 너무 짧거나 의미 없는 댓글 제외
```

베스트 의견 예시:

```text
오늘의 베스트 찬성 의견
“감정적으로는 남겼으면 좋겠지만, 지금 팔아야 리빌딩 자금이 생긴다.”

오늘의 베스트 반대 의견
“브루노를 팔면 맨유는 당장 전진 패스를 해줄 선수가 없다.”
```

## 11. 게시물 상태값

프리미어리그 이슈는 확정 여부가 중요하다.

따라서 모든 루머성 게시물에는 상태값을 표시한다.

```text
Monitoring:
관심 또는 관찰 단계

Interest:
구단이 관심을 보이는 단계

Contact:
접촉 또는 문의 단계

Talks:
협상 진행 단계

Advanced:
협상이 진전된 단계

Here We Go:
최상위 인사이더가 사실상 합의로 표현한 단계

Official:
구단 공식 발표

Denied:
관계자 또는 기자가 부인

Collapsed:
협상 결렬
```

상태값은 팬들이 루머의 무게를 이해하도록 돕는다.

## 12. 출처 신뢰도 표시

모든 게시물에는 출처를 표시한다.

```text
Tier 1:
매우 신뢰도 높은 현지 기자 또는 공신력 있는 매체

Tier 2:
클럽 담당 기자, 주요 스포츠 매체 기자

Tier 3:
보조 참고용 소스, 단독으로 사용하기 어려운 출처
```

예시:

```text
출처: David Ornstein
신뢰도: Tier 1
상태: Contact
```

주의사항:

```text
- 원문을 그대로 복사하지 않는다.
- 짧은 요약과 자체 해석으로 재가공한다.
- 출처 링크를 남긴다.
- 확정되지 않은 내용은 확정처럼 표현하지 않는다.
```

## 14. 관리자 운영 플로우

관리자는 해외 기자의 X 게시글 또는 해외 기사 기반 이슈를 확인하고 게시 여부를 결정한다.

## 14-1. 데이터 수집

```text
1. X Filtered Stream 또는 외부 수집 도구로 지정 계정의 게시글을 감지한다.
2. 감지된 게시글은 어드민 대기열에 들어간다.
3. 시스템이 관련 클럽/선수/키워드를 자동 태깅한다.
4. AI가 초안 제목과 요약을 생성한다.
```

---

## 14-2. 관리자 검수

관리자는 다음을 확인한다.

```text
- 이슈가 게시할 가치가 있는가?
- 출처가 충분히 신뢰 가능한가?
- 루머 단계가 적절한가?
- 일반/논쟁형/오늘의 토론 중 어떤 유형인가?
- 표현이 과장되거나 확정적으로 보이지 않는가?
```

---

## 14-3. 게시물 유형 선택

관리자는 게시물 등록 시 유형을 선택한다.

```text
일반 게시물:
정보 전달 중심

논쟁형 게시물:
찬반 투표가 가능한 이슈

오늘의 토론 게시물:
하루 1개 선정하는 메인 토론 이슈
```

---

## 14-4. AI 자동 생성 항목

AI가 생성하는 항목:

```text
- 한국어 제목
- 2~3줄 요약
- 관련 클럽/선수 태그
- 상태값 추천
- 게시물 유형 추천
- 찬성/반대 질문 추천
- 찬성 근거 1개
- 반대 근거 1개
- 인스타그램 카드뉴스 문구
- 캡션 초안
```

관리자는 반드시 최종 검수 후 게시한다.

## 18. 핵심 UX 규칙

```text
1. 사용자는 기본적으로 세로로 넘긴다.
2. 더 보고 싶은 이슈만 오른쪽으로 민다.
3. 오른쪽으로 밀었을 때 게시물 유형에 맞는 반응 화면이 나온다.

7. AI 분석은 오늘의 토론방에서만 보여준다.
8. 토론방은 하루 1개만 집중 운영한다.
9. 모든 루머는 출처와 상태값을 함께 보여준다.
10. 확정되지 않은 내용은 확정처럼 표현하지 않는다.
```

## 21. 최종 기획 요약

이 서비스는 프리미어리그 소식을 빠르게 전달하는 서비스가 아니다.

> 프리미어리그 이슈를 숏폼처럼 보고, 게시물 유형에 따라 댓글·투표·토론으로 참여하는 스포츠 이슈 피드 서비스다.

핵심 차별점은 다음과 같다.

```text
1. 릴스형 세로 피드
2. 우측 슬라이드 기반 반응 영역
3. 게시물 유형별 다른 참여 경험
4. 일반 게시물은 댓글 중심
5. 논쟁형 게시물은 찬반 투표 중심
6. 오늘의 토론 게시물은 실시간 토론방 중심
7. AI 분석은 오늘의 토론방에만 집중 적용
8. 출처와 루머 상태값을 함께 제공
9. 클럽/선수 개인화 피드로 확장 가능
```

최종 한 줄 정리:

> 프리미어리그 팬들이 이슈를 읽고 끝내는 것이 아니라, 넘기고, 밀고, 투표하고, 댓글 달고, 오늘의 토론방에서 함께 떠들게 만드는 서비스다.
